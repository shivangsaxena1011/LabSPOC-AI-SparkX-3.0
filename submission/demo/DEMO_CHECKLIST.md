# LabSPOC AI — Demonstration Recording Checklist (Release 0.9.0)

**Project:** LabSPOC AI — Spatially Grounded Virtual Lab Ambassador  
**Target Video Duration:** 4 to 6 minutes (Target: 5:45)  
**Presenter:** Shivang Saxena  

---

## 1. Pre-Recording Environment Checklist

- [ ] **Display Setup:** Resolution locked to 1920x1080 (16:9 widescreen), 100% DPI scaling (no UI blurriness).
- [ ] **Recording Software:** OBS Studio or Windows Game Bar configured at 1080p, 60fps, 8000 kbps CBR video bitrate, 320 kbps AAC audio bitrate.
- [ ] **Audio Setup:** Clean condenser microphone input with noise suppression and pop filter. Tested levels between -12dB and -6dB.
- [ ] **Local Demonstration Labeling:** If recording against local servers, clearly state during the opening: *"Demonstrating on local institutional deployment at http://localhost:3000"*.
- [ ] **Browser Preparation:** Use a clean Chromium browser profile in Fullscreen (F11), clean bookmarks bar hidden, devtools closed.
- [ ] **Clean Database Seed:** Ensure database is populated with verified sample assets (DGX Station A100, Jetson AGX Orin, VR Testing Bay) and approved SOPs.

## 3. Post-Recording Quality Review

- [ ] No private API keys, JWT secrets, passwords, or personal files visible on screen.
- [ ] Audio is synchronized with on-screen mouse movements and camera transitions.
- [ ] Video renders without frame drops or stuttering.
- [ ] Video export format: MP4 (H.264 / AAC), uploaded as unlisted on YouTube or Google Drive with public viewer link.
